# Changelog

All notable changes to the "Alphanetix Code Assistant" extension will be documented in this file.

## [1.0.0] - 2025-11-03

### Added
- ✨ Initial release of Alphanetix Code Assistant
- 🤖 Inline code completion powered by AI
- 💬 Interactive chat interface for coding assistance
- 👥 Multi-team support with team switching
- 📊 Real-time quota monitoring and warnings
- 🎯 Context menu actions (Explain, Fix, Refactor, Generate Tests, Generate Docs)
- ⚙️ Customizable settings panel
- 🔐 Secure authentication with JWT tokens
- 🌐 Browser-based login flow
- 📱 Status bar integration showing active team and quota
- 🎨 Beautiful sidebar UI with multiple views
- 🔄 Automatic token refresh
- 💾 Persistent state management
- 🚀 Support for all AI models and agents from AlphanetixAI platform
- 📝 Team-level system prompts and context
- ⚡ Fast and responsive inline suggestions
- 🛡️ Secure storage of credentials using VS Code secret storage

### Features
- **Inline Completion Provider**: Copilot-like code suggestions
- **Chat View**: Full-featured chat interface
- **Status View**: User info, quota, team, and model display
- **Settings View**: Easy configuration management
- **Code Actions**: Right-click menu integrations
- **Multi-language Support**: Works with all programming languages
- **Team Quota Tracking**: Monitor team credit allocation and usage
- **Low Quota Warnings**: Configurable threshold alerts
- **Model Selection**: Choose from available AI models
- **Agent Selection**: Pick AI agents for specialized tasks

### Technical
- Built with TypeScript
- VS Code Extension API integration
- Axios for HTTP requests
- Secure secret storage
- JWT token management
- Automatic token refresh
- Error handling and recovery
- Responsive webview UIs

## Version Format
This project follows [Semantic Versioning](https://semver.org/):
- **MAJOR**: Breaking changes
- **MINOR**: New features, backward compatible
- **PATCH**: Bug fixes, backward compatible

## Categories
- `Added` - New features
- `Changed` - Changes to existing features
- `Deprecated` - Features marked for removal
- `Removed` - Removed features
- `Fixed` - Bug fixes
- `Security` - Security improvements
